## 学习路线

- **HCIA**：交换、路由、VLAN、STP、OSPF、VRRP、DHCP、ACL、NAT
- **HCIP**：OSPF 深入、BGP 路由策略、企业网络互联
- **HCIE**：架构设计、网络优化、故障排查与项目实践

## 故障排查方法

遇到“访问不通”时，遵循从下到上的顺序：物理链路 → 接口状态 → VLAN/MAC → ARP → 路由 → ACL/NAT，并在每一步留下可复现的验证命令。
